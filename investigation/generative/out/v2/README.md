# Ten maps to play: M9 design version 2

Maps from the M9 design prototype, version 2 (0.7.0-proto2.1), 128², designed for Normal. They are our own maps. Each passes the product's checks in both validators, has no built dam wall and comes back byte for byte from its seed. Three are at high Verticality (85), with heights kept within 16.

**To play one:** copy its `.timber` file to `Documents\Timberborn\Maps`, then pick it under **New game**.
