# Sources

Quake reuses Dam Good Maps' MIT-licensed Carve prototype (`investigation/carve`, b14e23f), the available Craterize implementation (`investigation/craterize`, based on 62a8b97), and the repository's simulation, generator, formats and clean renderer.

Real places are loaded from the repository's existing compressed datasets, with their existing elevation and water attribution in `real-places/ATTRIBUTION.md` and each dataset. No external place data is copied into this investigation.

Three.js 0.186.0 is the same version as the repository. No game assets are included.
