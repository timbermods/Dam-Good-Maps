Can a web page call the Messages API directly?

Dam Good Maps' bring-your-own-key route (EDITOR_PLAN §7, route B) sends requests from the browser with the anthropic-dangerous-direct-browser-access header. This page sends one request with that header and one without, each with an obviously fake key. A readable 401 answer proves the browser allowed the page to read the response: CORS works. No real key is needed or used, and a request with a fake key costs nothing.
